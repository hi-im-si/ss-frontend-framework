# Modern Frontend Framework

A cutting-edge frontend framework built with React 18, TypeScript, and Tailwind CSS. Designed for modern web development with performance and developer experience in mind.

## 🚀 Features

- **React 18** - Latest React features including concurrent rendering
- **TypeScript** - Full type safety and enhanced developer experience
- **React Router v6** - Modern routing with nested routes and hooks
- **Tailwind CSS** - Utility-first CSS framework for rapid UI development
- **Vite** - Lightning-fast build tool with hot module replacement
- **ESLint** - Code quality and consistency
- **Responsive Design** - Mobile-first approach with modern UI components

## 🛠️ Tech Stack

- **Frontend**: React 18.2.0, TypeScript 5.2.2
- **Routing**: React Router DOM 6.20.1
- **Styling**: Tailwind CSS 3.3.5
- **Build Tool**: Vite 5.0.0
- **Linting**: ESLint with React and TypeScript rules
- **Package Manager**: npm

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone <your-repo-url>
   cd modern-frontend-framework
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:3000`

## 🎯 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
- `npm run lint:fix` - Fix ESLint issues
- `npm run type-check` - Run TypeScript type checking

## 🏗️ Project Structure

```
src/
├── components/          # Reusable UI components
│   ├── Header.tsx      # Navigation header
│   ├── Footer.tsx      # Site footer
│   └── Layout.tsx      # Main layout wrapper
├── pages/              # Page components
│   ├── Home.tsx        # Homepage
│   ├── About.tsx       # About page
│   ├── Contact.tsx     # Contact page
│   └── NotFound.tsx    # 404 page
├── App.tsx             # Main app component with routing
├── main.tsx            # Application entry point
└── index.css           # Global styles and Tailwind imports
```
